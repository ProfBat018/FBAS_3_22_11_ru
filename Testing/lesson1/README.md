# Отладка и тестирование 

Для того чтобы запустить отладку, нам надо установить React Dev Tools в Chrome. 


В общем и целом есть три способа тестирования:
- Cypress 
- Jest
- React Testing Library

## Cypress

Cypress - это инструмент для тестирования веб-приложений. Он позволяет писать тесты, которые будут выполняться в браузере. В нем есть много возможностей, например, можно отдельно тестировать компоненты, можно тестировать UI, можно тестировать API. При этом есть очень приятный интерфейс, который позволяет смотреть на то, что происходит во время тестирования.

Для того чтобы запустить тесты, нам надо установить Cypress. Для этого надо выполнить команду:

```bash

npm install cypress --save-dev

```

--save-dev - это флаг, который говорит о том, что пакет нужен только для разработки.

После установки нам надо добавить скрипт в package.json:

```json

"scripts": {
    "cypress:open": "cypress open"
}

```

После этого мы можем запустить тесты, выполнив команду:

```bash

npm run cypress:open

```
